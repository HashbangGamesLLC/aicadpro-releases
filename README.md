# AI CAD PRO downloads

**Build it yourself. Plan it together.**

AI CAD PRO is a free Windows 2D drafting app for DIY builders and homesteaders. Create and revise editable drawings for a house, tiny home, shed, workshop or solar project with an AI assistant.

- [Official website and current Windows download](https://aicadpro.com/)
- [Planning guides](https://aicadpro.com/guides/)
- [Worked tiny-home dimension and PDF-export example](https://aicadpro.com/tiny-home-plans/#dimension-study)

Use **Get it from Microsoft Store** on the official website for the current Windows distribution. The releases in this repository are historical standalone installers; they are not the recommended current download path. Application source is not published here.

## What you need

- A compatible 64-bit Windows PC; check the current Store listing for system requirements.
- An internet connection for AI assistance.
- Your own ChatGPT subscription or OpenAI API key. API requests are billed by OpenAI separately from the free app.

Projects are saved on your computer. AI CAD PRO is a drafting tool: check generated geometry, dimensions and notes. Drawings do not guarantee permit approval or replace required professional design and review.

## Installation and updates

Follow the Microsoft Store installation and update flow linked from the official website. For current setup guidance, see the website and in-app instructions. Avoid treating the legacy installer directions in old release notes as instructions for the Store version.
